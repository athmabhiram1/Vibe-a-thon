# 08 — Do Onboarding/HR/IT Builds Win? Winners-Fit Analysis

**Question:** Do onboarding / HR / IT-helpdesk builds win at Geek Room + MCP hackathons?
**Short answer:** No — not once as overall winner in any Geek Room event researched. They win *categories/tracks* elsewhere when a sponsor names the track. Municipal/telecom alternatives score higher on novelty at Geek Room; onboarding scores higher on sponsor-fit at enterprise/MCP-adjacent events. Pick based on which hackathon you enter.

## 3. Fit scoring: onboarding vs municipal vs telecom

Scale 1–5 (5 = best). Scored for **Geek Room-style open hackathons** unless noted.

| Criterion | Onboarding/HR/IT agent | Municipal (civic grievance) agent | Telecom (support/complaint) agent |
|---|---|---|---|
| Novelty at Geek Room | 2 — judges have seen 100 HR chatbots; VoiceRx/health cluster shows crowded-utilitarian builds don't place | 4 — civic + voice + memory is fresh; social-good angle matches Safire/CK2.0 DNA | 3 — commerce-adjacent (ShopperMan won on transactional voice); less fresh than civic |
| Demo story (60-sec stage) | 2 — "answers policy questions" is flat on stage | 5 — pothole → photo → complaint filed → status tracked; audience *feels* it | 4 — angry-customer → voice agent resolves → human handoff; strong but familiar |
| Mandatory-stack leverage (Vapi voice + Qdrant memory) | 3 — voice FAQs + retrieval fit, but shallow | 5 — voice complaint intake + RAG on past grievances + status memory = full use | 4 — voice support + semantic runbook retrieval (cf. Token Titans HM) |
| Sponsor-hire appeal (100+ companies in room) | 5 — every company has onboarding pain; best for hiring conversations | 3 — civic doesn't hire | 3 — telcos hire, but narrower |
| MCP-track fit (Freshworks/TGPF, Solo.io-style) | 5 — *explicit* Track 1 example ("Employee Policy Agent", "Knowledge-to-Action"); Konveyor precedent won Python category at Microsoft | 2 — no MCP track names civic; governance judges want infra | 3 — maps to "Voice Support Agent" example, but competes with every CX bot |
| Win-probability (Geek Room overall) | 2 | 4 | 3 |
| Win-probability (enterprise/MCP-sponsored) | 4 | 2 | 3 |

## 4. Recommendation

- **If entering Geek Room open hackathon (HackBLR/Vibe-style):** lead with **municipal**, keep onboarding as stretch/track-2. Civic gives the Konichiwa/Safire-style stage story + full Vapi+Qdrant showcase. Frame onboarding module as "day-2 expansion" in deck, not the headline.
- **If entering Freshworks TGPF / enterprise-agent / MCP-governance event:** lead with **onboarding/HR-IT** — it is literally the example in the brief, and Konveyor proves HR-adjacent wins categories there. Add MCP tool calls (file ticket, provision access, book buddy) so it's "Knowledge-to-Action", not a FAQ bot — that distinction is the judging criterion.
- **Telecom** is the hedge: re-skin municipal voice-intake pipeline to complaint-triage if the problem statement drops a CX track. Same architecture, different seed data.
- Whatever the headline, **ship one transactional action** (file/provision/escalate with ID + status lookup) — every winner analysis converges on this: ShopperMan transacts, Safire hides+reports, Frugalia fixes waste, Konveyor transfers knowledge. Pure Q&A never wins.
