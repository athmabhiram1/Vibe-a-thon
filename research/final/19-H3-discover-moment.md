# H3 — Live `--discover` Moment Decides Track 3

**Claim:** A live `--discover` run (agent probing an unknown API and surfacing tools in front of judges) is the single decisive wow/clarity moment for Track 3 — more than slides or pre-canned output.

**Null (H0):** Demo format makes no difference; judges score live-discover and pre-canned demos within 0.5 pts (10-pt scale) and pick each ~50% in pairwise choice.

**Falsification criterion (specific observation that kills H3):** In A/B dry-run judging with n≥6 mock judges (same API, same narration, only discover-live vs screenshot/pre-canned differs), if live version scores <1.0 pt higher on wow/clarity OR wins ≤3/6 pairwise picks, H3 is FALSIFIED.

**Alternative (if falsified):** Use pre-canned discover output + polished slides for reliability; reallocate rehearsal time to Q&A hardening.

**Priority:** P1 — decides demo script and rehearsal risk budget (live demos fail).

**Verification method:**
1. Two 3-min demo cuts: (A) live `agent --discover <unknown FastAPI URL>` + tool list on screen, (B) static screenshot of same output.
2. 6+ mock judges score wow (1–10) + clarity (1–10) + pairwise pick; record failure handling (if live stalls >15s, count as loss).
3. Require 2 successful live runs in rehearsal to qualify.

**Expected outcome:** Live version +1.5–2.5 pts on wow, wins ≥5/6 picks; judges cite "saw it figure it out" in comments. Action on confirm: open Track 3 demo with live discover, keep pre-canned fallback on hotkey.
