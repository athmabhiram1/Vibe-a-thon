# Code Kshetra 2.0 — Winners Research

**Event:** Code Kshetra 2.0 — 36-hour national hackathon, JIMS Sector-5 Rohini, Delhi, **Feb 21–23, 2025**.
**Organizers:** Geek Room × JIMS Rohini. **Season:** MLH 2025. **Powered by:** Groq, Pathway, Reactive Network, AI Hello.
**Scale:** 14,500+ applications (<5% accepted), Top 150 teams on-site, ~30% outside Delhi, ~17% industry pros.
**Prize pool:** 5 Lakh+ (cash ~₹50,000+ per Devfolio; sponsor prizes ≈ $12,482 listed).

**Method note:** Code Mode catalog had no searxng/firecrawl tools (verified via `search()`), so research used
`default.websearch` (16 queries) + `default.webfetch` (9 page fetches: LinkedIn posts, Devfolio, JIMS Facebook post,
member portfolios, GitHub). LinkedIn/Devfolio JS pages returned partial content.

## Pattern Notes (for winner-prediction model)

- Both top teams were **AI-applied-for-social-good** style builds (harassment shield; GenAI-heavy team that went on to win an AI hackathon) — aligns with Groq/Pathway/AI-Hello sponsorship slant.
- Repeat-winner signal: Pixel Minds won HackWIE 3.0 ~8 days earlier with the same project + iteration; PartTimeHumans won again at IIT Bombay months later.
- Small teams (3–4), cross-role (full-stack + AI + design), Delhi-NCR colleges overrepresented (MSIT ×2 of 4 listed teams).
- Mentor-linked teams placed: Pathway mentor Saksham Goel mentored the 2nd-place team; ML mentor Manav Gupta credited by 1st-place team.
